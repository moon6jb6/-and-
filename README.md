# 城市碳核算与政策分析框架 · 交互地图

一个单文件、零依赖、可离线打开的交互式框架地图，覆盖 **137 个核算对象 / 26 个一级模块 / 8 层结构**。

## 在线访问

**https://moon6jb6.github.io/-and-/**

## 它解决什么问题

把一张 137 行的能源—碳—经济核算总表，重构成可以点开看的活文档：点任意层级，立刻看到该部分的**第一性原理**与**最新进展**。

三层粒度，逐级下钻：

| 点击对象 | 看到什么 |
|---|---|
| **层按钮**（顶部 8 个） | 该层的第一性原理 + 本层各模块进度，并自动滚到该层 |
| **模块卡**（26 个） | 第一性原理 / 核心核算式 / 已核实参数清单 / 待补缺口（带任务单编号） |
| **条目 chip**（137 个） | 该条行号、所属模块、核算式、阻断它的待补数据 |

## 数据状态（真实标注，非装饰）

26 个模块按实际核实进度分三色，**62 条已核实参数 / 47 项待补缺口**：

- 🟢 **已核实** 3 个 —— 官方一手来源齐备，可直接计算
- 🟡 **部分可用** 11 个 —— 方法明确，部分参数待补
- 🔴 **待补参数** 12 个 —— 缺关键参数，暂不能出自洽数值

已核实部分包含但不限于：

- 生态环境部 2022 年**全国 + 7 大区 + 30 省电力 CO₂ 排放因子**全表
- 2023 / 2024 年**电力碳足迹因子**（0.6205 → 0.5777 kgCO₂e/kWh）
- 2025 年**全国碳市场**运行数据（3,378 家纳管、累计成交 8.65 亿吨、均价 62.36 元/吨）
- 2025 年 **CCER** 数据（12 项方法学、33 个项目、1,776.37 万吨、均价 70.76 元/吨）
- IPCC **AR6** 关键 GWP 值

## 功能

- **搜索**：输入「电力」「CCER」「稻田」，命中条目高亮、未命中淡出
- **状态筛选**：全部 / 已核实 / 部分可用 / 待补参数
- **键盘可用**：Tab 聚焦，Enter / Space 触发
- **响应式**：窄屏单栏，宽屏左侧地图 + 右侧常驻详情面板
- **零依赖**：纯 HTML + 内联 CSS/JS，不加载任何外部资源，断网可用

## 三条对账恒等式

页面底部列出，用于校验框架内所有数字：

```
碳流平衡：碳输入 = 大气排放 + 产品固碳 + 废物残渣 + Δ库存 + 地质封存
口径对账：属地 + 调入 − 调出 = 消费端
净排放：  净排放 = 总排放 − 净移除量
```
