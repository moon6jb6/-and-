# 城市碳核算与政策分析框架 · 交互地图

一个单文件、零依赖、可离线打开的交互式框架地图，覆盖 **137 个核算对象 / 26 个一级模块 / 8 层结构**。

**在线访问 → https://moon6jb6.github.io/-and-/**

> 当前版本 **v2**（2026-10-30）：按第一轮学术审计意见修正了 3 处实质性错误，并补入模块级证据链与单位体系。详见 [第一轮审计响应](audit-response-round1.md)。

---

## 它解决什么问题

把一张 137 行的能源—碳—经济核算总表，重构成可以点开看的活文档：点任意层级，立刻看到该部分的**第一性原理**、**核算公式**、**最新进展**与**证据链**。

三层粒度，逐级下钻：

| 点击对象 | 看到什么 |
|---|---|
| **层按钮**（顶部 8 个） | 该层的第一性原理 + 各模块进度，并滚到该层 |
| **模块卡**（26 个） | 第一性原理 / 核算公式 / 已核实参数 / 待补缺口 / 证据链 |
| **条目 chip**（137 个） | 行号、所属模块、核算式、阻断它的待补数据、证据链 |

## 数据状态

26 个模块按核实进度分三色，**71 条参数（附来源）/ 52 项待补缺口**：

- 🟢 **已核实** 3 个 —— 官方一手来源齐备
- 🟡 **部分可用** 11 个 —— 方法明确，部分参数待补
- 🔴 **待补参数** 12 个 —— 缺关键参数，暂不能出自洽数值

⚠️ **「已核实」的定义边界**：指该表述可追溯到政府公告/统计公报原文并已逐字比对，**不等于**该参数适用于任意城市、任意年份。适用条件见各模块的「口径限定」条目。

## 功能

- **搜索**：输入「电力」「CCER」「稻田」，命中条目高亮、未命中淡出
- **状态筛选**：全部 / 已核实 / 部分可用 / 待补参数
- **证据链**：每个模块底部列出对应官方文件，含文号、发布日期、可点击链接
- **单位体系**：总览面板列出 8 项量纲规范
- **键盘可用**：Tab 聚焦，Enter / Space 触发
- **响应式**：窄屏单栏，宽屏左图 + 右常驻面板
- **零依赖**：纯 HTML + 内联 CSS/JS，不加载外部资源，断网可用

## 三条对账恒等式

```
碳流平衡（边界闭合时）：
  化石碳输入 + 调入 = 大气排放 + 产品固碳 + 废物残渣 + Δ库存 + 封存 + 调出
口径对账：属地 + 调入隐含碳 − 调出隐含碳 = 消费端（需 MRIO）
净排放：  净排放 = 总排放 − 净移除量
```
