**2026 年四行业配额方法**（发电用基准法，三行业用系数法，两者都叫「强度」但不是同一个公式）：

```
发电：      A = A_e + A_h
            A_e = Q_e × B_e × F_f      （2026 基准值 0.7894 / 0.7985 / 0.8080 / 0.3288 tCO₂/MWh）
            A_h = Q_h × B_h            （供热 0.1021 / 0.0533 tCO₂/GJ）
钢铁/水泥/铝： A = E × (1 + α)
            X = (BP − I) ÷ BP          （BP 行业平衡值，I 企业工序吨产品碳排放量）
            −20% < X < 20% → α = 0.15X；X ≥ 20% → +0.03；X ≤ −20% → −0.03
```

> ⚠️ **α 方向是最容易写反的一处**：`α > 0` 表示企业强度**优于**行业基准，配额 A > 排放 E，形成**盈余**（奖励先进）；`α < 0` 表示**劣于**基准，A < E，形成**缺口**。本项目第一版曾把方向写反，已在 v3 修正。

### 2. 电力因子拆成 5 条独立序列

原先把不同口径的因子并列在同一张表里，读者会默认它们构成一条时间序列。现在按序列拆开，每条单独记录年份 / 区域 / 单位 / 适用场景：

| 序列 | 值 | 单位 | 用途 |
|---|---|---|---|
| 电力消费 CO₂ 因子（全国） | 2022 `0.5366` → 2023 `0.5306` | kgCO₂/kWh | 范围二，地理口径（清单法） |
| 电力消费 CO₂ 因子（市场口径） | 2022 `0.5856` → 2023 `0.6096` | kgCO₂/kWh | 购绿电记 0 + 剩余电量乘此因子 |
| 化石能源电力 CO₂ 因子 | 2022 `0.8325` → 2023 `0.8273` | kgCO₂/kWh | 仅化石电源 |
| 电力消费 CO₂ 因子（区域） | 华北 0.6361 / 东北 0.5122 / 华东 0.5500 / 华中 0.5271 / 西北 0.5543 / 南方 0.4042 / 西南 0.2472 | kgCO₂/kWh | 区域电网核算 |
| 电力平均碳足迹因子 | 2023 `0.6205` → 2024 `0.5777` | kgCO₂e/kWh | 产品碳足迹（生命周期） |

**禁止跨序列拼接**：单位不同（kgCO₂ vs kgCO₂e）、口径不同（清单 vs 生命周期）、分母不同（全社会电量 vs 化石电量）。

### 3. 公式修正

| 模块 | 修正前 | 修正后 |
|---|---|---|
| 能源转换 | 「发电排放与热效率无关」 | 总排放 `E = Q_f×NCV×CC×OX×44/12` 与排放强度 `EF = (CC×OX×44/12) ÷ η` 分列 |
| MRV | `U = √ΣUᵢ²`（仅适用于独立误差） | 含协方差的一般式 + A/B 类不确定度 + 相关矩阵 + 蒙特卡洛 + 敏感性分析 |
| 碳流 | `碳输入 = 大气排放 + 产品固碳 + 废物 + Δ库存 + 封存` | 一般控制体 `C_in − C_out + C_gen − C_cons − ΔS = 0`，化石碳/生物源碳/产品储碳/废物碳分账 |
| 消费端 | `属地 + 调入 − 调出 = 消费端` | 同上，但明确标注为**恒等式非算法**：调入调出须同为隐含碳且口径一致，求解需 MRIO |

### 4. 状态体系：单轴 → 双轴

v2 用单一 `status` 标注 26 个模块，结果 **15 个模块与缺口清单自相矛盾**（「已核实」仍列缺口、「待补」却无缺口清单、11 个「待补」模块同时列着已核实参数）。

v3 拆成两个独立指标：

- **方法成熟度 M**（M0–M4）：公式是否明确、有无官方/学界标准方法学
- **数据完备度 D**（D0–D4）：参数是否齐全、有无来源、能否出数

三色状态由 `(M, D, 缺口数)` 派生，并加生成期硬断言：

```
D < 4  ⟹  至少 1 项缺口
已核实  ⟹  缺口数 = 0
模块必须双轴标定
```

### 5. 证据链：模块级 → 参数级

为每条参数单独登记 **来源编号 / 数据年份 / 单位 / 适用范围** 四个字段，并如实区分两类：

| 指标 | 数量 | 说明 |
|---|---|---|
| 参数总条目 | **87** | 所有模块「最新进展 · 已核实」的条目总数 |
| 已绑定文号级来源 | **63** | 可指向具体文件（含文号/公告号）且登记了年份、单位、适用范围 |
| 仅模块级 | **24** | 方法学陈述、跨来源综合判断或框架自建规则，非单一文件可追溯 |
| 待补缺口 | **63** | 编号对应 `missing_data_spec.py` |

> **口径声明**：「已绑定文号」只保证该条**可追溯到文件**，不保证已核对页码。页码级核验（page-level citation）仍需逐条打开原文比对，属下一步工作。因此 63 条**不等于** 63 条已完成学术级引用审查。

## 三、一致性保证：单一事实源

上一版的实质问题之一是**网页改了、静态图没改**——`framework-map.svg` 里 `0.5306`、`协方差`、`MRIO`、`V02` 出现次数全为 0。

v3 从结构上解决：`framework_core.py` 是唯一数据源，HTML 与 SVG 都从它生成，并在生成期断言：

```python
# SVG 生成器
_missing = [k for k in KEY_FIGURES if k not in _svg]
assert not _missing, "SVG 缺少与 HTML 共享的关键数字: %s" % _missing
```

KEY_FIGURES 含 `0.5306` / `0.6096` / `0.8273` / `CCER—14—002—V02` / `A = E × (1 + α)` / `C_in − C_out + C_gen − C_cons − ΔS = 0` / `LMDI`，任一缺失即构建失败。

## 七、四条对账恒等式

```
碳流平衡（一般控制体）：C_in − C_out + C_gen − C_cons − ΔS = 0
口径对账（需 MRIO）：  属地 + 调入隐含碳 − 调出隐含碳 = 消费端
配额盈缺：            缺口 = E − A
净排放：              净排放 = 总排放 − 净移除量
```
