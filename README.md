## 一、为什么重构

上一版的定位是「碳核算平台」。这个定位的问题是：**碳排放只是能源经济系统的结果变量。**

真正需要解释的是：能源从哪里来、如何生产、如何流动、如何消费、如何定价、如何影响经济，以及未来如何转型。只做核算，等于只测体温不查病因——能说清「排了多少」，说不清「为什么增长」「价格怎么形成」「转型冲击落在谁身上」。

v4 因此把结构改成：

```
能源供给 → 能源需求 → 市场与价格 → 能源产业 → 碳排放（结果）
                                              ↓
            能源安全 ← 能源技术 ← 政策制度 ← 宏观经济
                                              ↓
                        区域能源经济 · 国际能源经济 → 未来情景
```

碳排放（05）仍在，但从「系统的全部」变成「系统的第五块」。

## 四、8 层证据体系

回答「凭什么让人相信这个结论」——这是原框架最薄弱的部分。

| 层 | 必须回答 | 硬规则举例 |
|---|---|---|
| E1 统计数据 | 数据来自哪、口径是什么、有无缺失与修订 | 一手优先；同指标两源交叉；差异>5% 必须解释 |
| E2 核算方法 | 能耗、转换损失、排放如何算 | 发电煤耗 ≠ 供电煤耗；三种碳口径不可拼接 |
| E3 经济模型 | 价格、供需、产业关联、宏观影响如何建模 | 先定用途再选族；弹性必须给估计来源与置信区间 |
| E4 因果识别 | 政策究竟造成了什么影响 | 交错处理下 TWFE 权重可为负，须换估计量 |
| E5 空间分析 | 生产、消费、运输、排放如何跨区关联 | 行政边界 ≠ 电网边界 ≠ 经济区边界 |
| E6 不确定性 | 误差对结论影响多大 | 区分 A/B 类；误差相关性不可默认独立 |
| E7 国际比较 | 差异来自资源、技术还是制度 | 统一 PPP 与热值口径；资源差异与制度差异政策含义相反 |
| E8 情景预测 | 依赖哪些假设、改假设是否稳定 | 至少三情景；与碳平衡/电力平衡做一致性校验 |

## 五、每条研究问题的登记格式

```python
Q("01-05", "01", "L2", "新能源装机增长是否真正转化为有效能源供给？…",
  ind=[("有效出力系数", "%", "实际发电量 ÷ (装机×8760)"),
       ("弃风/弃光率", "%", "(可发电量 − 实际发电量) ÷ 可发电量"),
       ("利用小时数", "h", "发电量 ÷ 装机容量")],
  data=["D3", "D7", "D6"],          # 所需数据集
  model=["M01", "M21"],             # 适用模型
  ev=["E1", "E2"],                  # 证据层次
  status="可算")
```

生成期断言：每条问题必须挂 ≥1 个带算式的指标、≥1 个数据集、≥1 个模型、≥1 个证据层次；ID 与引用编号必须存在。

|---|---|---|---|
| 🟢 可算 | 20 | 19% | 算式明确且数据有公开来源 |

## 六、数据锚点：50 条数值，18 条可追到官方原文

研究问题需要指标，指标需要数值，**数值必须能追到出处**。本系统唯一的数字来源清单是「数据锚点」页——凡页面出现的中国能源经济数值，都应能在该页找到对应行与来源链接。

| 状态 | 条数 | 含义 |
|---|---|---|
| 🟢 已核实 | 18 | 直接抓取到一手官方页面（stats.gov.cn / nea.gov.cn / gov.cn / 欧盟委员会），数值出现在正文或表格中 |
| 🟡 部分核实 | 31 | 权威机构数据但经二手转述；或只有增速/区间无绝对值；或存在两套并行口径 |
| 🟣 计算值 | 1 | 由核查者换算或推导（如弃电率 = 100 − 利用率），非官方发布 |
| 🔴 未核实 | 7 | 检索后仍无可信来源，已逐条列出检索路径与建议 |

原始核查表 52 条中 **只有 16 条（30.8%）能追到一手官方页面原文**，29 条（55.8%）靠二手转述，7 条（13.5%）无法核实。这不是检索不力，是中国能源统计的真实可得性——公开数据大量存在于公报、图片表、JS 渲染页与行业协会 PDF 中。

### 五个口径陷阱（本页最重要的一节）

1. **两套煤炭与发电量口径并存**：统计公报用全口径（2025 原煤 48.5 亿吨、发电量 105752.5 亿kWh），《能源生产情况》月报用规上口径（2025 原煤 48.3 亿吨）。差 0.2 亿吨，混用直接串年份。
2. **装机是期末累计**：用「新增装机」与「累计装机」做同比是常见错误。
3. **利用率跨年不可比**：国能发电力〔2024〕44号把新能源利用率改为「仅考虑系统原因受限电量」计算，2024 年起与之前不完全可比；且利用率 ≠ 100%−弃电率。
4. **碳市场「均价」有三种算法**：成交额÷成交量、日均收盘价均值、年末收盘价。2025 年三者分别约 62.4、约 60、74.63 元/吨，差 20%。
5. **对外依存度不是官方统计指标**：由智库/协会按「净进口÷表观消费」自算，是否含成品油各家不同。

### 三处内部不一致的处理

| 编号 | 矛盾 | 处理结论 |
|---|---|---|
| I-01 | 2025 天然气产量增速 公报 +6.3% vs 能源局 +6.2% | 两套口径（全口径 vs 规上），跨口径算 2620.6/2464−1=6.36% 两头都不是，证明基数不同。增速只在同口径内可比 |
| I-02 | 2025 碳市场成交量 2.35 亿吨 vs 23.46 亿吨 | **已定案**：146.30÷2.35=62.26 元/吨 与公布均价 62.36 吻合；取 23.46 则为 6.24 元/吨，差 10 倍。反算 146.30÷62.36=2.346 亿吨。**23.46 是小数点错位** |
| I-03 | CBAM 因子 2030 年 51.5% 与「每年 −2.5pp」不自洽 | 矛盾来自「线性递减」假设本身。EU 免费配额退出是**非线性阶梯**，中间年份待 EUR-Lex 原文核对，在取得原文前不填充 |

## 七、数据补充任务总表：110 项，按四个标准拆开

「63 项缺口」不等于「63 项没数据」。真正要回答的是四个独立问题：

| 标准 | 取值 | 为什么要分开 |
|---|---|---|
| **存在性** exist | 有 / 部分 / 无 | 「存在但拿不到」与「不存在」是两件事，对策完全不同 |
| **可取得性** access | 公开 / 受限 / 不可得 | 公开=可下载；受限=需采购/申请/涉密/无 API |
| **可计算性** compute | 直接 / 需计算 / 需模型 / 不可 | 需计算不是缺数据，是缺做除法的人 |
| **可追溯性** trace | 一手 / 二手 / 无 | 决定它能支撑多强的结论 |

配套三级来源机制：**L1 官方直接**（34 项）/ **L2 权威库或研究估算**（50 项）/ **L3 模型推算**（26 项）。
L3 的值必须标 `estimated=True`，**不得与官方统计值混列**。

### 四标准实测分布（110 项）

| 维度 | 分布 |
|---|---|
| 存在性 | 有 38 / 部分 54 / **无 18** |
| 可取得性 | **公开 71** / 受限 21 / **不可得 18** |
| 可计算性 | 直接 41 / 需计算 35 / 需模型 28 / 不可 6 |
| 可追溯性 | 一手 42 / 二手 50 / 无 18 |

**关键结论**：110 项里真正「不存在」的只有 18 项、「不可得」只有 18 项，其余 92 项都有获取路径——其中 **37 项是「公开可得但还没采」**，60 项需要计算或建模。

| 可获取未取 | **21** | 公开可得、算式明确，只是还没采（如 AR6 GWP 表、CBAM 参数、CCER 方法学正文、稻田 CH₄ 因子） |

### 数据记录 Schema（19 字段）

必填项含 `value`（缺失填 `None`，**禁止填 0**）、`data_type`（official/research/estimated）、`quality_level`（A 一手可复现 / B 二手可追溯 / C 估算有法 / D 无法追溯）、`estimated`、`task_id`。完整字段见页面「数据补充总表」页。

### 四张核心关联表

`能源数据表`（键 region+year+energy_type+flow）↔ `经济数据表`（键 region+year+sector+indicator）↔ `技术参数表`（键 tech+year+region）↔ `政策事件表`（键 policy_id）。

每张表都标注了一条**最容易违反的恒等式或陷阱**，例如能源平衡表恒等式不满足即口径不一致；政策事件表的「发文日 ≠ 生效日 ≠ 数据可见日」会让 DID 的效应估计系统性偏移。

### 六阶段执行顺序

清理缺口 → 全国年度 → 省级面板 → 单城市完整平衡 → 碳/产业链/政策 → 模型层。

## 八、30 个数据集与 22 个模型

数据集每条登记**发布机构 / 频率 / 覆盖 / 已知口径局限**。例如：

- `D2` 中国能源统计年鉴：发布滞后 12–18 个月，最新年份常需以统计公报替代
- `D11` 电力 CO₂ 因子公告：分四类因子（消费/市场/化石电源/碳足迹），单位与口径不同，**禁止跨序列拼接**
- `D15` 区域间投入产出表：消费端核算唯一可靠基础，但表龄滞后、非竞争型进口拆分需假设
- `D30` 企业级报送：不对外开放，无公开 API

模型每条登记**数学形式 + 适用限度**。例如：

- `M02` LMDI：无残差可完全加和，但**是会计归因不是因果**
- `M13` 电力现货出清：出清价 = 功率平衡约束的对偶变量，对机组参数与网络拓扑敏感
- `M15` LCOE/学习曲线：对折现率与利用小时极敏感，跨来源比较前必须统一这两个假设
- `M19` DID/合成控制：交错处理下 TWFE 权重可为负
