## 二、每个模块的八段结构

同一套结构，保证读者能沿一条完整的解释链读下去：

| 段 | 内容 | 目的 |
|---|---|---|
| 01 | 基本概念 | 解释研究对象是什么 |
| 02 | 第一性原理 | 解释其底层逻辑 |
| 03 | 运行机制 | 解释变量之间如何相互作用 |
| 04 | 发展历程 | 解释它是如何形成和演变的 |
| 05 | 当前发展状态 | 用真实数据说明现实情况 |
| 06 | 核心矛盾 | 解释目前存在什么问题 |
| 07 | 分析方法 | 解释学界如何研究 |
| 08 | 政策与未来 | 解释可能的发展方向 |

### 举例：不是只给一个 LCOE 公式

K13「成本与技术」是这样写的：

- **基本概念**：LCOE 是把全生命周期成本与电量折算到同一基准后相除，本质是「把不可比的成本变成可比」
- **第一性原理**：不同技术寿命、燃料成本、建设期都不同，直接比每千瓦投资毫无意义；但 LCOE 压平时间维度的同时引入了对折现率与利用小时的极度敏感
- **核心矛盾**：折现率从 5% 调到 8%，煤电与光伏的相对优势可能逆转；LCOE 不含并网、调峰、备用，**低估高比例新能源的系统成本**
- **政策与未来**：焦点正从 LCOE 转向系统成本与价值——同样电量在正午与晚峰价值完全不同，孤立 LCOE 排序会越来越失真

这样才是解释知识，而不是罗列指标。

| 方法 | 操作 | 说明 |
|---|---|---|

## 六、构建与复现

```bash
python knowledge_core.py      # 16 模块 × 8 段完整性 + 交叉引用校验
python gen_knowledge_html.py  # 生成 index.html（知识体系主页面）

python energy_core.py         # 分析视图数据（12×4 / 107 问 / 资源）
python gen_energy_html.py     # 生成 explorer.html
python gen_energy_svg.py      # 生成 energy-map.svg

python framework_core.py      # 碳子模块
python gen_framework_html.py  # 生成 carbon.html
python gen_framework_svg.py   # 生成 framework-map.svg
```

`knowledge_core.py` 的断言：

```
16 个知识模块，编号唯一
每个模块八段结构全部非空（概念≥2、机制≥3、历程≥3、状态≥2、矛盾≥2、方法≥3）
每个部分至少 2 个模块
模块引用的研究域 / 研究问题 / 数据锚点必须真实存在
```
